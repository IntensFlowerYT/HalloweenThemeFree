# 🎃 HALLOWEEN THEME FREE

A free Halloween theme for Discord.

## ✨ Features

* Haunted purple and pumpkin orange colors
* Dark gothic atmosphere
* Custom hover effects
* Glowing accents
* Halloween-inspired interface

## 📦 Installation

1. Install BetterDiscord.
2. Download `HalloweenThemeFree.theme.css` from this repository.
3. Move the file into your BetterDiscord themes folder.
4. Enable HALLOWEEN THEME FREE in Discord settings.
